## 历史源码比对

补发采用源码基线 `3f765cfe276dc8fa44fce672931e2a336feb5c10`，该提交早于 AMO 文件创建时间。两个浏览器目标分别与对应商店包比较：

- 每个包均有 15 个扩展文件，除商店签名与校验元数据外，没有额外运行文件。
- 每个包的 14 个非 manifest 文件与历史源码逐字节相同。
- Chrome 与 Edge 的 manifest 只需去除各商店加入的 `update_url`，JSON 内容便与源码一致。
- Firefox manifest 的 JSON 内容与源码一致，仅文件字节格式不同。
- 后续文档提交 `4bbbc52` 的扩展源码相同；比对确定了运行内容基线，不据此声称找回了唯一上传提交。
- 9 月的前台同步修正、俄语、西班牙语与匿名统计兼容测试不属于这个商店版本。

原始上传 ZIP 的哈希和 Chrome / Edge 的首次公开日期未找回；已通过公开包逐文件核验运行内容，不用新构建包冒充原始上传包。
